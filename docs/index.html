Outlook ICS Normalizer

Open-source Google Apps Script software that reads an Outlook ICS calendar feed, corrects all-day recurrence exceptions, and maintains copies in a dedicated Google calendar in your own account.

Each user controls their own installation and private configuration. Calendar synchronization runs on Google infrastructure. Optional GitHub Actions update the installed source after a validated pull request is merged.

Google authorization

The deployment client requests permission to create and update Apps Script projects, plus basic account identity. Calendar access and timer permissions belong to the separately authorized runtime installation.
